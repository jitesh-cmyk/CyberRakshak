# 🛡️ CyberRakshak – Digital Fraud Recovery Assistant

**From confusion to organized action.**

CyberRakshak is a responsive web application designed to help people understand what to do after experiencing an online fraud or cyber incident. It provides step-by-step guidance, evidence organization, recovery progress tracking and cyber safety awareness.

🌐 **Live Demo:** https://cyberrakshak-ten.vercel.app/

💻 **GitHub Repository:** https://github.com/jitesh-cmyk/CyberRakshak

## 🚀 Features

- **Dashboard:** Overview of saved incidents and recovery progress.
- **Incident Selection:** Support for UPI fraud, social media hacking, fake job scams, online shopping fraud and phishing.
- **Evidence Manager:** Organize incident details and evidence checklists.
- **Recovery Progress Tracker:** Track important recovery actions.
- **Report Generator:** Generate a printable incident summary and save it as PDF.
- **Emergency Actions:** Quick access to India's cybercrime reporting resources.
- **Fraud Prevention Tips:** Learn how to avoid common online scams.
- **Cyber Safety Quiz:** Test your cybersecurity awareness.
- **Language Support:** English and Hindi interface.
- **Responsive Design:** Works on desktop and mobile devices.

## 🛠️ Technology Stack

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/jitesh-cmyk/CyberRakshak.git
   ```

2. Open the project folder:

   ```bash
   cd CyberRakshak
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🚨 Official Cybercrime Resources (India)

- **Cyber Fraud Helpline:** 1930
- **National Cyber Crime Reporting Portal:** https://cybercrime.gov.in/

For financial cyber fraud, report immediately through the official channels. Do not share OTPs, UPI PINs, passwords or full card details.

## 🔐 Privacy & Responsible Use

- Incident records are stored locally in the browser using LocalStorage.
- Do not enter passwords, OTPs, UPI PINs or complete card details.
- Clearing browser data may remove locally saved records.
- CyberRakshak is an educational guidance and incident-organization tool.
- It does not automatically investigate criminals, recover money or file official complaints.
- It is not an official government service.
